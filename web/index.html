Today

  • Racks look full – people circle around or give up.
  • Free spaces at the far end are never found.
  • Bikes end up on fences, railings and escape routes.

With Smart Bike Station

Running in three steps

  1. 1

    Mount the sensors

    One distance and one vibration sensor per space, an Arduino per rack. Existing racks stay.

  2. 2

    Pair the Pi

    One command on the Raspberry Pi – or the Home Assistant add-on. The pairing code comes from the portal, done in 60 seconds.

  3. 3

    See it live

    Portal, kiosk screen at the station and phone view update within seconds.

Everything a busy bike station needs

Live occupancy

Free, occupied or unknown – per space, with a timestamp. Missing data is never shown as “free”.

Space recommendation

Arrivals see the next free space immediately – with a transparent, fixed rule.

Movement warnings

Repeated strong shaking at a parked bike raises a warning: a suspicion to check, never proof. Rule and AI are compared openly.

Planning heatmap

Occupancy by weekday and hour shows when the station is full – data for your next investment.

Kiosk, phone, three languages

A high-contrast display at the station, a QR code for phones, English, German and Dutch – states always with text and symbol.

Secure by default

Roles, two-factor sign-in, audit log, encrypted transport, device tokens per station.

Security and privacy built in

  • No cameras, no names, no RFID – only space, state and time.
  • Runs in the cloud or on your own server (Proxmox, Docker) – your data stays yours.
  • Two-factor sign-in, account lockout, secure sessions, audit log.
  • Encrypted transport, certificate pinning for the gateways, checksum-verified updates with rollback.
  • Automatic deletion after the retention period, export and deletion in one click.
  • Warnings are hints, not accusations – deliberately factual wording.

Sustainable by design

  • Uses your existing racks – no new infrastructure.
  • About 4 W per station (Pi + Arduino + sensors), ≈ 35 kWh per year estimate
  • Better used racks mean fewer new ones – and more people choosing the bike.
  • LED brightness adjustable, no screens required.

Frequently asked questions

What happens if the internet goes down?

The Pi buffers measurements and sends them later; LEDs at the spaces keep working. Screens show “unknown” instead of a wrong “free”. Self-hosted in your LAN, the internet is not needed at all.

Can we host it ourselves?

Yes. One command on a Proxmox host creates a container with the complete platform – no domain and no mail server needed. Docker works too.

How long does the installation take?

Mounting the sensors of a rack takes about an hour. Pairing a Raspberry Pi takes about a minute: create a code in the portal, run one command.

Which hardware do we need?

A Raspberry Pi, an Arduino, one distance sensor and one vibration sensor per space, LEDs. Everything is standard – see the starter kit above.

Is it GDPR-compliant?

It is built for data minimisation: no cameras, no personal data about cyclists, automatic deletion, export and deletion for customers. The operator still needs its own privacy notice – templates are included.

Is it accessible?

States are always shown with text and a symbol (never colour alone), everything works with the keyboard, the kiosk view uses high contrast and large type, in three languages.

How do we cancel?

Monthly, in the portal. You can export all data as JSON and delete your organisation completely at any time.
